This assignment is designed to evaluate how you approach frontend development, backend development, GraphQL API design, database modeling, authentication, state management, validation, and code quality. You should aim for a clean, working, maintainable implementation without unnecessary features.

Problem Statement
Build a Typing Speed Game Application where users can test their typing speed by completing a sequence of randomly generated alphabets.
The application should allow users to:
Start a typing challenge with a timer starting from 0 seconds.
Type 20 randomly generated alphabets using the keyboard.
Display one alphabet at a time.
Move to the next alphabet only when the correct key is entered.
Apply a 0.5 second penalty for every incorrect key press.
Keep the keyboard/input focused throughout the game.
Display progress, such as 10 / 20.
Display the final score after completing all 20 characters.
Show Success if the user beats their previous best score; otherwise show Failure/Try Again.
Treat a lower completion time as a better score.
Store the best score locally.
Allow users to restart and play again.
You are free to design the interface in your own style.
